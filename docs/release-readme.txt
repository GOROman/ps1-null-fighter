御意見有用 (NULL FIGHTER) - PlayStation 用 CD イメージ

同梱ファイル
  nullfighter.cue / nullfighter.bin   CD イメージ（cue + bin。2 つを同じフォルダに置いてください）
  MANUAL.md                           操作説明
  CHANGELOG.md                        変更履歴
  VERSION.txt                         このビルドのバージョンとコミット

遊び方
  エミュレータ: DuckStation などで nullfighter.cue を開きます。
  実機:         ImgBurn 等で nullfighter.cue を CD-R に焼きます（cue を指定すると bin も読まれます）。
                実機で起動するには改造 / バックアップ起動ができる本体が必要です。
