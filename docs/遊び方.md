# 遊び方

「御意見有用」の遊び方ガイドです。

## モード選択

起動するとタイトル画面が表示されます（背景で CPU 同士のデモ対戦）。十字キー上下でモードを選び、START で開始。

| モード | 内容 |
|---|---|
| 1P MODE | パッド 1 の P1 vs CPU |
| VS MODE | パッド 1 の P1 vs パッド 2 の P2 |
| CPU MODE | CPU 同士（観戦） |

1P / VS の試合は 2 本先取（最大 3 ラウンド）。試合が終わるとタイトルに戻ります。

## 格闘モード操作

バーチャファイター方式の P / K / G で操作します。

### 基本操作

| 操作 | 動作 |
|---|---|
| 十字キー 左右 | 前進 / 後退 |
| △ (P) | パンチ |
| ○ (K) | キック |
| □ (G) 押しっぱなし | ガード |
| START + SELECT | タイトルへ戻る |

### パンチ技

| 操作 | 技 |
|---|---|
| △ | ジャブ |
| 前 + △ | ストレート |
| 後 + △ | フック |
| 下 + △ | アッパー |

### キック技

| 操作 | 技 |
|---|---|
| ○ | ハイキック |
| 前 + ○ | 回し蹴り |
| 後 + ○ | 後ろ蹴り |
| 下 + ○ | 足払い |

### 必殺技（P + K 同時押し）

| 操作 | 技 |
|---|---|
| △ + ○ | スピニングバードキック |
| 前 + △ + ○ | ドラゴンキック |
| 後 + △ + ○ | ハリケーン |
| 下 + △ + ○ | スライディング |

### コンボ

攻撃中に P または K を押すと次の技につながります（最大 4 連）。

## バトルシステム

### ガード
- □ を押している間ガード状態
- 立ちガードは中・上段攻撃を削りダメージに抑える
- 下段技とダウン技はガードを抜ける

### カウンターヒット
- 攻撃中の相手に技を当てるとカウンターヒット（1.5 倍ダメージ、COUNTER! 表示）

### リングアウト
- ステージ端（±4200）まで吹き飛ばすとリングアウト勝利

### その他
- 無傷で勝つと PERFECT 表示
- 連続ヒット数が表示される

## ビューアモード

タイトル画面で START + SELECT を押すとビューアに入ります。

Dancing Eyes 風のミニゲームで、猿がスカートの格子を歩き、囲った区画の布が落ちます。

### ビューア操作

| 操作 | 動作 |
|---|---|
| 十字キー | 猿の進行方向（分岐で選択、入力がなければ乱数） |
| 左スティック | カメラ回転 |
| 右スティック 上下 | カメラ上下 |
| SELECT + 十字キー | カメラ回転（デジタルパッド用） |
| SELECT + △ / × | カメラ上下 |
| SELECT + □ | 布をリセット |
| △ / × | ドリー（距離） |
| □ / ○ | 画角ズーム |
| L1 | モデル回転 |
| R1 / START+SELECT | IK モード ON/OFF（入ると腰のダンスが始まる） |
| L2 / R2 | アニメ切替（IK モード外） |
| START 単押し | キャラ切替（制服 / 金髪 / 3 人目） |
| START + SELECT | タイトルへ戻る |
| L3 | アニメ一時停止 |

## 対戦キャラクター

格闘モードは金髪キャラ vs 制服キャラ（3 人目）の対戦です。

- ライフゲージ
- タイマー
- ROUND / FIGHT! / K.O. 表示
- ヒットストップと画面揺れ
- ヒットエフェクト（当たった手足の位置に表示）
- 使った技名の表示
