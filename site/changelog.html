2026-09-04最新

  • タイトル画面を追加。1P MODE（パッド 1 vs CPU）/ VS MODE（パッド 1 vs パッド 2）/ CPU MODE（観戦）
  • パッド操作に対応。バーチャファイター方式の △P / ○K / □G、P+K で必殺技、方向キーで派生技、攻撃中の追加入力で最大 4 連チェイン
  • 1P / VS は 2 本先取の試合が終わるとタイトルへ戻る
  • 格闘モード: 32 技の技テーブル（パンチ 8 / キック 12 / 必殺技 12）、ガード（削りダメージ、下段技とダウン技は抜ける）、カウンターヒット（1.5 倍）、リングアウト、PERFECT 表示、連続ヒット数表示
  • 制服キャラ（3 人目）を P2 に
  • 当たり判定を打撃部位（手・足・膝・頭）の実位置で判定。ハイキックは腰より上でのみヒット
  • 攻撃中は打撃部位が相手の軸を通るように体の向きを補正
  • スピニングバードキック（多段ヒット）を劣勢時の切り返しとして追加
  • AI の戦略化: 相手の出がかり / 硬直 / のけぞり、距離帯、体力差、残り時間から行動を選ぶ。P1 は攻め、P2 は待ち
  • コンボ（ジャブ→ジャブ→膝→ハイキック など 12 種）、硬直キャンセルでの連係、ダウンと起き上がり
  • ヒットストップ、画面揺れ、ヒットエフェクト、技名表示
  • 格闘モードを 60fps 化（対戦用に 600 三角形の軽量モデル）
  • GitHub Actions でビルドし、cue / bin / 操作説明 / 変更履歴を zip にしてリリース
