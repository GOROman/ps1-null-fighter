システム

SYSTEM
ガード

中段・上段を削りダメージに抑える。下段技（足払い、スライディング）とダウン技はガードを抜ける。削りでKOにはならない。

カウンターヒット

相手の攻撃中に当てると1.5倍ダメージ。COUNTER!表示。

リングアウト

ステージの端まで吹き飛ばせば、その場で勝ち。

ラウンド

60秒、2本先取。時間切れは残り体力の多い方が勝ち。無傷ならPERFECT。

連続ヒット

のけぞり中に当て続けるとHITS数が表示される。

戦略AI

CPUは出がかり・硬直・距離・体力差・残り時間を読んで行動を選ぶ。

攻略メモ
  • 相手が技を振った直後の硬直に、ジャブ → ジャブ → 膝 → ハイキックを差し込む。
  • ガードで固まる相手には下 + ○ の足払い。ガードを抜けて転ばせられる。
  • 端に追い詰めたら大技で吹き飛ばしてリングアウト。
  • 体力が減ったら一歩下がり、突っ込んできたところにカウンターを合わせる。
