ストーリーSTORY

199X 年、東池袋。

世界各地で腕利きの格闘家が次々と姿を消していた。裏で糸を引くのは、ワインの流通網を隠れ蓑に世界征服を企む悪の組織 シャルドネ。総帥は、選び抜いた格闘家に禁断の洗脳術「熟成」を施し、意思のない最強の戦闘兵器へと造り変えていた。

そして今夜、シャルドネからの招待状が届く。

世界最強を決める大会「御意見有用」を開催する。勝ち残った者には、何でも望みを一つ叶えよう。

集まった格闘家たちは知らない。この大会が、次の「熟成」候補を選ぶための品評会であることを。

ナル・ブランドーは、消えた師の行方を追ってリングに上がる。音有A子は、洗脳された親友を取り戻すために制服のまま会場へ乗り込む。

すべての意見は、拳で述べよ。

遊び方HOW TO PLAY

モード

1P MODE

パッド 1 の P1 vs CPU。2 本先取、最大 3 ラウンド。

VS MODE

パッド 1 の P1 vs パッド 2 の P2。友達と対戦。

CPU MODE

CPU 同士の対戦を観戦。AI の戦略を眺める。

タイトル画面で十字キー上下でモードを選び、START で開始。試合中に START+SELECT でタイトルに戻ります。

バトルシステムSYSTEM

ガード中段・上段を削りダメージに抑える。下段技（足払い、スライディング）とダウン技はガードを抜ける。削りで KO にはならない。
カウンターヒット相手の攻撃中に当てると 1.5 倍ダメージ、COUNTER! 表示。
リングアウトステージの端まで吹き飛ばすとその場で勝ち。
ラウンド60 秒。時間切れは残り体力の多い方が勝ち。2 本先取。
PERFECT無傷で勝つと表示。
連続ヒットのけぞり中に当て続けると HITS 数が表示される。

初心者のコツ

  • 相手が技を振った直後の硬直に、ジャブ → ジャブ → 膝 → ハイキックを差し込む。
  • ガードで固まる相手には下 + ○ の足払い。ガードを抜けて転ばせられる。
  • 端に追い詰めたら大技で吹き飛ばしてリングアウトを狙う。
  • 体力が減ったら少し下がって距離を取り、突っ込んできたところにカウンターを合わせる。

御意見の書き方HOW TO SEND FEEDBACK

このゲームは GitHub Issues（御意見フォーム）に書かれた要望やバグ報告を AI が読んで実装し、CI/CD が自動でビルドしてリリースすることで育ちます。遊んで気づいたことは何でも歓迎です。

  1. 御意見フォームを開き、「要望」か「バグ報告」を選ぶ（GitHub アカウントが必要です）。
  2. フォームの項目を埋める。カテゴリ、内容、理由、関係するモードなど。
  3. 送信すると Issue になります。実装されると Issue にコメントが付き、最新版に反映されます。
伝わりやすい書き方
「前 + P + K でサマーソルトキックが欲しい。今は対空技がなくてジャンプキックに困るから」
「1P MODE の 2 ラウンド目、リングアウトした瞬間に相手が起き上がって二重に KO 表示が出る。毎回起きる。DuckStation 0.1-7000」
伝わりにくい書き方
「もっと面白くして」
「バグってる」
どこで、何をしたら、どうなったか、本当はどうなってほしいかがあると AI が動けます。

ネタの例

  • 新しい技やコンボ、必殺技のコマンド変更
  • ダメージや技の出の速さなどバランスの感想
  • CPU の強さ、難易度選択、キャラ追加、ステージ
  • 表示や操作の改善、エフェクト、サウンド
  • ストーリーやキャラ設定への意見も歓迎
