# 御意見有用

![ROUND 1](docs/screenshot-fight.png)

**初代 PlayStation 向けの 3D 対戦格闘ゲーム**

開発: **東池袋ナル**

---

## ストーリー

199X 年、東池袋。

世界各地で腕利きの格闘家が次々と姿を消していた。裏で糸を引くのは、ワインの流通網を隠れ蓑に世界征服を企む悪の組織 **シャルドネ**。総帥は、選び抜いた格闘家に禁断の洗脳術「熟成」を施し、意思のない最強の戦闘兵器へと造り変えていた。

そして今夜、シャルドネからの招待状が届く。

> 世界最強を決める大会「御意見有用」を開催する。勝ち残った者には、何でも望みを一つ叶えよう。

集まった格闘家たちは知らない。この大会が、次の「熟成」候補を選ぶための品評会であることを。

ナル・ブランドーは、消えた師の行方を追ってリングに上がる。音有A子は、洗脳された親友を取り戻すために制服のまま会場へ乗り込む。

すべての意見は、拳で述べよ。

## ゲームシステム

- 3D ステージでの 1 対 1。ステージ端まで吹き飛ばせば **リングアウト**
- **P / K / G** の 3 ボタン。方向キーとの組み合わせで技が変わり、攻撃中に追加入力で最大 4 連の連係
- **ガード** は中段・上段を削りダメージに抑える。下段技とダウン技はガードを抜ける
- 相手の攻撃中に当てれば **カウンターヒット**（1.5 倍）
- ラウンドは 60 秒、2 本先取。無傷で勝てば **PERFECT**
- CPU は相手の出がかり・硬直・距離・体力差・残り時間を読んで戦う

### モード

|---|---|

## 皆様の意見でゲームが進化します

**「御意見有用」は、皆様の声で育つ格闘ゲームです。**

遊んで気づいたこと、欲しい技、バランスの感想、バグ報告 — なんでも「御意見フォーム」に書いてください。

- **要望やバグを見つけたら** → AI が実装します
- **push のたびに自動ビルド** → cue / bin と操作説明・変更履歴入りの zip をリリース

## このプロジェクトについて

旧称 NULL FIGHTER。ソースやビルド成果物の名前（`nullfighter.cue` など）には旧称が残っています。

**このリポジトリのコードとツールは、すべて Claude Code（Claude Fable 5.1）だけで書かれています。** 人間がやったのは日本語で要望を出すこと、画面を見て感想を返すこと、素材を渡すことだけです。

素材も生成 AI 製です。キャラクターのデザイン画は ChatGPT、そこからのモデル・テクスチャ・リグ・アニメーションは Tripo3D で作りました。PSn00bSDK で書かれていて、実機相当の 60fps で動きます。
